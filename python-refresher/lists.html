1What a list is

So far each variable held one value. A list holds many values, in order, under one name. You write it with square brackets and commas.

nums = [7, 3, 9, 4, 1]
names = ["Ada", "Linus", "Grace"]
mixed = [42, "hi", 3.5, True]   # any types, even mixed
empty = []

print(len(nums))     # how many items
print(9 in nums)     # is 9 somewhere in the list?
print(list("abc"))   # a string split into its characters
Output5
True
['a', 'b', 'c']

Index: one item

Every item has a position called its index, and counting starts at 0. So the first item is nums[0] and the last of 5 is nums[4]. Negative indices count from the end: nums[-1] is always the last item.

Slice: a piece of the list

nums[start:stop:step] works exactly like range(start, stop, step): it starts at start, stops before stop, and moves by step. Leave a number out to mean "from the beginning", "to the end" or "every item". A slice is a new list; nums does not change.

Result
nums[0]  →  7
nums = [7, 3, 9, 4, 1]
print(nums[0], nums[-1])   # first and last
print(nums[1:4])           # index 1, 2, 3
print(nums[:2], nums[3:])  # first two, from index 3 on
print(nums[::2])           # every second item
print(nums[::-1])          # reversed copy
Output7 1
[3, 9, 4]
[7, 3] [4, 1]
[7, 9, 1]
[1, 4, 9, 3, 7]
IndexError nums[5] on a 5-item list stops the program with IndexError: list index out of range; the last index is len(nums) - 1. A slice never raises it: nums[3:99] just gives [4, 1].
Connects to what you know: range() and slices share one rule: start is included, stop is not. nums[1:4] picks indices 1, 2, 3, just like range(1, 4).

2Changing a list

Numbers and strings never change; you always make a new one. Lists are different: you can change them in place. These methods change the list itself.

You writeWhat happens
nums.append(6)adds 6 at the end
nums.insert(1, 8)puts 8 at index 1; everything after it shifts right
nums.pop()removes the last item and gives it back; pop(0) removes the first
nums.remove(9)deletes the first 9 it finds (ValueError if there is none)
nums[0] = 5replaces the item at index 0
nums.sort()puts the list in order; nums.reverse() flips it
nums + [10, 11]a new list joining both; nums is unchanged

Two names, one list


b = nums does not copy the list. It ties a second tag to the same list, so a change through b shows up in nums too. When you want a separate list, ask for one: nums.copy() or nums[:].


nums = [1, 3, 4]
b = nums          # same list, two names
c = nums.copy()   # a new, separate list
b.append(5)
c.append(99)
print(nums)
print(c)
Output[1, 3, 4, 5]
[1, 3, 4, 99]


sort() gives back None nums = nums.sort() throws your list away: sort() changes the list and returns None, so nums becomes None. Write nums.sort() on its own line, or use sorted(nums), which returns a new sorted list and leaves nums alone.


Connects to what you know: in the refresher, total = price * qty kept 12 after qty changed, because numbers can't change. A list can. With b = nums, changing the list changes what both names see.

3Looping over a list


A for loop can walk straight through a list: the loop variable takes each item in turn. You don't need range(len(...)) unless you also want the index, and then enumerate() gives you both.


nums = [3, 8, 1, 9]
total = 0
for i, n in enumerate(nums):   # i is the index, n is the item
    print(i, n)
    total += n
print(total, sum(nums), min(nums), max(nums))
print(sorted(nums), nums)
Output0 3
1 8
2 1
3 9
21 21 1 9
[1, 3, 8, 9] [3, 8, 1, 9]

4List comprehension


A lot of loops do one thing: build a new list from an old one. A list comprehension writes that whole loop in one line.



  
[n * n for n in nums if n % 2 == 1]

  

    
expressionwhat to put in the new list for each item

    
for clausewhere the items come from, and the name each one gets

    
if clauseoptional: keep only the items where the test is True

  




It means exactly the same as this loop. The parts are in a different order:


result = []
for n in nums:              # for clause
    if n % 2 == 1:          # if clause
        result.append(n * n)   # expression


The figure lays the parts out as rows, top to bottom in the order an item travels. The item leaves the source list, is tested on the if pad (if the test is False it drops away), becomes the expression's value on the next pad, and lands in the new list. Under the figure, the matching line of the loop version lights up at the same time.


The same thing as a for loop
Output


The three shapes you'll write most


nums = [7, 3, 9, 4, 1]
print([n * 2 for n in nums])                  # change every item
print([n for n in nums if n > 4])             # keep some items
print([n * n for n in nums if n % 2 == 1])    # both
print([i * i for i in range(1, 6)])           # from a range
print([w.upper() for w in ["hi", "list", "py"]])
Output[14, 6, 18, 8, 2]
[7, 9]
[49, 9, 81, 1]
[1, 4, 9, 16, 25]
['HI', 'LIST', 'PY']


if at the end vs if-else at the front


The two ifs do different jobs and go in different places:


    

  • if at the end filters. Items that fail are left out, so the new list can be shorter: [n for n in nums if n > 4].
    • 

  • if … else at the front is part of the expression. Every item is kept, and each one becomes one value or the other: ["even" if n % 2 == 0 else "odd" for n in nums] gives ['odd', 'odd', 'odd', 'even', 'odd'].
    • 

  • [n for n in nums if n > 4 else 0] is a SyntaxError. An else only goes in the front part.
    • 



Connects to what you know: your "Remove the vowels" homework in one line: "".join([c for c in text if c.lower() not in "aeiou"]). The loop with continue and the comprehension do the same job.


When not to use one Use a comprehension to build a list. If you only want to print things, or the logic needs several lines, an ordinary for loop is clearer. Readable code beats short code.
