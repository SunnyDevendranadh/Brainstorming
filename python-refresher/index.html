1Variables

A variable is a name that holds a value. You make one with =, which works right to left: Python first works out the value on the right, then sticks the name on the left onto it.

price = 4             # make the name price, give it 4
qty = 3
total = price * qty   # right side first: 4 * 3 = 12
qty = 5               # qty now holds 5; the old 3 is gone
print(total)          # still 12: total was worked out when qty was 3
Output12

Naming rules

  • Use letters, digits and _, and do not start with a digit: score2 is fine, 2score is a SyntaxError.
  • Case matters: Score and score are two different names.
  • Keywords like if, for and True cannot be names.
  • Write snake_case: total_price, not TotalPrice or tp.
  • Don't reuse a built-in's name. sum, input, print, str and list are already tools. sum = 0 hides the real sum(), and later sum([1, 2]) crashes with TypeError: 'int' object is not callable.

input() always gives you text

input() shows its prompt, waits for Enter, and returns what was typed as a str, even when you type digits. Convert it before you do maths with it.

a = float(input("First number: "))
b = float(input("Second number: "))

print("Product:", a * b)

4Conditions

if runs a block only when its test is True. elif ("else if") adds more tests, and else catches whatever got past all of them. Python checks the tests top to bottom and runs only the first block whose test is True.

score = int(input("Score: "))

if score >= 90:
    print("A")
elif score >= 80:     # only checked when score < 90
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")

print("Done")         # not indented: runs every time
OutputScore: 72

Syntax and indentation errors

  • Forgot the colon: if x > 3 gives SyntaxError: expected ':'
  • Forgot to indent: IndentationError: expected an indented block after 'if' statement
  • Use 4 spaces per level, every time. Everything indented under the if belongs to it; the first line back at the left edge is outside it.

Nested loops and for … else


A loop inside a loop runs the inner loop completely for every pass of the outer one. A for loop can have an else: it runs only if the loop finished without a break. That is how your prime finder knows a number had no divisor:


n = 20
for num in range(2, n + 1):
    for d in range(2, num):
        if num % d == 0:
            break           # found a divisor: not prime
    else:
        print(num, end=" ")  # no break happened: prime
Output2 3 5 7 11 13 17 19
